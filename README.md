# Blinkit_Data_Analysis
# 🛒 Blinkit Data Analysis & Power BI Dashboard

This repository contains an end-to-end **data analysis and visualization project** based on **Blinkit grocery sales data**.  
The project focuses on extracting actionable business insights using **Excel** and **Power BI**, and presenting them through an interactive dashboard.

---

## 📌 Project Objectives

- Analyze Blinkit grocery sales performance
- Understand customer purchasing behavior
- Identify top-performing products and outlets
- Evaluate sales trends across categories and locations
- Build an interactive dashboard for decision-making

---

## 🧰 Tools & Technologies Used

- **Microsoft Excel** – Data cleaning and preprocessing  
- **Power BI** – Data modeling and dashboard creation  
- **Data Analysis Techniques** – Aggregation, filtering, KPI analysis

---
## 📊 DataSet Overview

The dataset includes key business attributes such as:
-Item Type & Category
-Outlet Size & Location
-Sales Value
-Customer Ratings
-Outlet Establishment Year
-The data was cleaned and structured before being loaded into Power BI for analysis.

📦 Identification of top-selling product categories
🏬 Performance comparison of outlets by size and location
⭐ Relationship between ratings and sales
